# 🚀 CI/CD Pipeline Implementation Using Jenkins & Docker

## 📌 Project Overview

This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline using Jenkins and Docker.

The pipeline automates the process of building, containerizing, and deploying an application whenever new code is pushed to the GitHub repository.

This helps reduce manual effort, improve deployment speed, and ensure consistent application delivery.

---

## 🎯 Objectives

- Automate build and deployment process
- Reduce manual errors
- Improve development workflow efficiency
- Implement real-time CI/CD pipeline
- Deploy containerized application on server

---

## 🛠️ Technologies Used

- Git & GitHub – Version control
- Jenkins – CI/CD automation tool
- Docker – Containerization
- AWS EC2 – Deployment server
- Linux – Server environment
- Node.js – Sample application

---

## ⚙️ Project Workflow

1. Developer pushes code to GitHub repository.
2. GitHub webhook triggers Jenkins pipeline.
3. Jenkins pulls the latest code.
4. Jenkins builds the Docker image.
5. Docker container is created and started.
6. Application is deployed on AWS EC2 server.
7. Application becomes live automatically.
